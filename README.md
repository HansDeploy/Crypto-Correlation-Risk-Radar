# 📡 Crypto Correlation Risk Radar

🔗 **[Launch Live App](https://crypto-correlation-risk-radar-ckappppunwzsv54txsrnrsq.streamlit.app/)**

A professional financial analytics tool that helps investors understand if their crypto portfolio is truly diversified, or if their assets are secretly moving together. 

## 🚀 Features
- **Smart Search & Logos:** Select assets easily with a modern search bar and real-time coin logos.
- **Interactive Heatmap:** A visual matrix showing correlation coefficients (-1 to 1) to instantly spot high-risk overlaps.
- **Network Graph:** A visual mapping of how coins are interconnected based on their historical price movements.
- **AI-Powered Insights:** Integrated with **Groq (Llama 3)** to identify coin narratives (e.g., Layer 1, DeFi, AI) and explain statistical risks in plain English.
- **Portfolio Risk Score:** A dynamic 0-10 score that evaluates the overall risk of your selected portfolio based on average correlation.

## 🛠️ Tech Stack
- **Frontend:** Streamlit (Custom Dark UI)
- **Data:** CoinGecko API (365-day historical data)
- **AI Engine:** Groq API (Llama 3)
- **Analytics:** Pandas, NumPy, Plotly
